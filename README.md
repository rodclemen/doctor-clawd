# Doctor Clawd

A fourth universe for [Clawd Clash](https://github.com/rodclemen/clawd-clash), in progress: your AI coding sessions as a pixel-art time-travel battle on your macOS desktop.

Nothing is released yet. [PLAN.md](PLAN.md) has the cast, places, signature moves, transitions and the phases. The code is being built on the `doctor_who` branch of Clawd Clash.
